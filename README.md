# Event Management System

## Overview

A desktop-based Event Management System developed using Java Swing, JDBC, and MySQL. The application helps manage events, clients, venues, staff, vendors, and services through an interactive graphical user interface.

## Technologies Used

* Java
* Java Swing
* JDBC
* MySQL

## Features

* User Authentication
* Client Management
* Venue Management
* Staff Management
* Vendor Management
* Service Management
* Event Management
* Dashboard Analytics
* Search Functionality
* CRUD Operations

## Database Design

The project uses a normalized MySQL database with foreign key relationships to maintain data integrity between entities such as Events, Clients, Staff, Vendors, Services, and Venues.

## Project Structure

src/
└── project/
└── EventManagementApp.java

## Setup Instructions

1. Clone the repository
2. Create the MySQL database
3. Execute the SQL schema script
4. Update database credentials in the Java file
5. Run EventManagementApp.java
